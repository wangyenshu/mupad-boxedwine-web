Click OK on the "unregistered" notice, click the input line, type e.g. int(sin(x)^2, x) and press Enter (Shift+Enter starts a new line). Plots such as plotfunc2d(sin(x), x = -PI..PI) open in VCam Light; ?int opens the help.

  • Wait for "Ready, kernel online" in the status bar before pressing Enter on the next input. A new input sent while MuPAD is still computing crashes the emulator; reload the page if that happens.
  • Don't minimize windows: there is no taskbar to bring them back, and the screen stops updating. Close plot and help windows instead.
  • The first start registers MuPAD's programs and takes about a minute; later starts are quicker.
  • Files you save (e.g. under C:\users\username\Documents) are kept in this browser (IndexedDB).
  • Add ?resolution=1280x1024 to the URL for a larger screen, ?sound=true for sound.
